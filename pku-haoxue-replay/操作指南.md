# 北大好学回放下载器 · 操作指南

一个在 Windows 上批量下载“北大好学”课程回放的小工具。它在电脑上直接下载课程视频，不解密账号密码，也不操作 App 界面。

## 它能做什么

- 按课程、日期、节次下载回放，自动合成 MP4
- 每天增量缓存新增回放（可选）
- 把 App 里手动下载的课程视频自动转成 MP4（可选）
- 登录失效时提醒你，而不是静默失败

## 你需要准备

1. Windows 10/11 电脑
2. [MuMu 模拟器](https://mumu.163.com/)（12 代即可），并在里面安装“北大好学”
3. Python 3.10 或更高版本（安装时勾选 **Add Python to PATH**）
4. 你自己的北大账号（登录由你在模拟器里完成）

## 安装

### 方式 A：让 AI 帮你装（推荐）

把整个 `pku-haoxue-replay` 文件夹（或 zip 解压后的文件夹）交给 AI，对它说：

> 按这个文件夹里的 AGENT_SETUP.md 帮我安装和配置，输出目录用 `D:\Videos\haoxue`。

AI 会检查环境、安装依赖、写配置、验证下载。登录那一步它会让你自己在模拟器里完成。

### 方式 B：自己装

1. 解压文件夹，进入目录，打开 PowerShell。
2. 安装依赖：

```powershell
python -m pip install -r .\requirements.txt
```

3. 启动 MuMu，打开好学并登录。
4. 运行安装脚本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -TargetDir "D:\Videos\haoxue"
```

5. 自检：

```powershell
$skill = Join-Path $env:USERPROFILE ".qoder-cn\skills\pku-haoxue-replay"
python "$skill\scripts\pku_replay_cache.py" check
```

看到“登录状态有效”就装好了。

## 日常使用

先进入脚本目录：

```powershell
cd "$env:USERPROFILE\.qoder-cn\skills\pku-haoxue-replay\scripts"
```

### 查今天有什么回放

```powershell
python pku_replay_cache.py list --date 2026-10-20
```

### 下载某节课

```powershell
python pku_replay_cache.py download --course 概率论 --date 2026-10-20
python pku_replay_cache.py download --course 概率论 --date 2026-10-20 --section 第3-4节
```

### 先看看会下载什么（不实际下载）

```powershell
python pku_replay_cache.py download --course 概率论 --date 2026-10-20 --dry-run
```

### 补下历史回放

```powershell
python pku_replay_cache.py sync --since 2026-09-01
```

### 完全不操心：定时自动缓存

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\.qoder-cn\skills\pku-haoxue-replay\install.ps1" -CreateTasks
```

会注册两个计划任务：

- **PKU Replay Sync**：每天 00:00 / 06:00 / 12:00 / 18:00 自动缓存新增回放
- **PKU Video Convert**：每 10 分钟把 App 内已下载的视频转成 MP4

## 文件都在哪

| 内容 | 位置 |
|------|------|
| 下载的 MP4 | `haoxue_config.json` 里的 `target_dir`（默认 `%USERPROFILE%\Videos\haoxue`） |
| 下载日志 | `<skill>\scripts\replay_cache.log` |
| 配置 | `<skill>\haoxue_config.json` |
| 登录失效标记 | 输出目录下的 `NEED_LOGIN.txt` |

## 登录过期怎么办

脚本发现 token 失效时，会在输出目录写 `NEED_LOGIN.txt`，并弹 Windows 通知。你只需要：

1. 打开 MuMu 里的“北大好学”
2. 重新登录
3. 再跑一次 `check`

不需要把密码告诉任何人或任何 AI。

## 常见问题

**Q：下载失败，说回放“待生成”？**  
老师刚下课，回放可能还没生成。过几小时或第二天再试。

**Q：提示“没有找到课程”？**  
用 `list --date 日期` 看看当天的准确课程名；有些课不在“我的课程”列表里，但按日期能查到。

**Q：同名课程有多条？**  
`list --date` 会显示 course_id，下载时加 `--course-id`。

**Q：输出目录能改吗？**  
可以。编辑 `haoxue_config.json` 的 `target_dir`，或重新运行 `install.ps1 -TargetDir "新目录"`。

**Q：会不会把我的视频或账号传出去？**  
不会。脚本只在本机运行，token 只存在本机缓存文件里，视频只写入你指定的目录。

**Q：不想自动下载某些课？**  
编辑 `haoxue_config.json` 的 `excludes`，例如 `["普通物理", ["经济学原理", "讨论课"]]`。

## 隐私与使用边界

- 只下载你本人账号有权访问的课程内容
- 不要分享、上传或再分发课程视频
- token 等同于登录凭据，不要发给别人
- 卸载时删除 skill 目录和计划任务即可，已下载的 MP4 会保留
